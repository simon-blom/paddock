# Phase 10 TP=2 prefill/decode overlap — architectural boundary

Status: design only. The accepted bounded decode pipe is commit `4f0ef919cb0e62017307aac820779a46a4ffcd2d`. This document does not enable `supports_overlap` or modify its production path. TP graphs, speculation and offload stay out of scope.

## Why the implementation stops here

Overlap is not a second CUDA stream around the existing `prefill()` call. The current rank model has one `token`/`x`/`xn`/`logits`/sampler-parameter scratch set and one stream (`tp_model.rs:56-76,216-235,445-545`). FFN, GQA and DeltaNet each hold additional mutable working buffers (`ffn_tp.rs:36-46,109-127`; `gqa_tp.rs:92-123,217-249,308-508`; `delta_tp.rs:199-263,435-456,468-629`). DeltaNet's slot state is temporarily swapped into a common pair; disjoint slots alone do not protect it. Rank 0's large-vocabulary `sample_rows` A/B/C path also uses the pack's process-global `pd_sr_*` scratch (`packs/cuda/src/deltanet/stage2_sample.cuh:2230-2249,2439-2455`). A naive forked executor would silently race model activations, layer intermediates, metadata uploads and sampler reductions.

The current prefill is a blocking one-token `run_rows` loop that copies full logits each step (`tp_serve.rs:281-293,505-520`). The worker refuses prefill commands during a pipe flight (`tp_serve.rs:948-955`); the coordinator does likewise (`tp_serve.rs:671-674`). The scheduler's overlap route requires a nonblocking unified span and a slot-mapped pipe together (`generator.rs:217-266`; `service.rs:3767-3873`). The ordered TCP command protocol and sole NCCL communicator do not identify an independent prefill flight or impose a two-lane collective order. Simply lifting the command exclusion would risk mismatched collectives and unreleasable KV/state. This crosses the model, per-layer primitives, distributed protocol, sampler and scheduler contracts; it is substantially larger than a localized Phase 10 continuation. The accepted pipe remains untouched.

## Minimum viable construction, in dependency order

1. Split each rank's immutable weights/geometry from mutable execution state. Retain a single physical allocation of each weight shard. Give the prefill and decode lanes distinct `GpuExecutor` streams (the existing `fork_stream()` at `gpu/mod.rs:911-941` is the available primitive), top-level activations, metadata, logits, sampler parameters and every FFN/GQA/DeltaNet working buffer. Keep each slot's GQA KV and DeltaNet recurrent/conv payload single-owned; never duplicate live state or schedule the same slot on both lanes. Do not use a second loaded model, which would duplicate weights and diverge in state. Make lane/slot ownership checkable before any KV authorization.
2. Implement a bounded prefill chunk queue for TP. A correctness-first chunk may enqueue serial one-token forwards on the prefill stream, but it must not read intermediate full-vocabulary logits or block the host on each row. Authorize/mirror each KV Ensure before its use; retain final-row logits/ID in prefill-lane storage until an event signals completion. `unified_span_launch(budget, fin_plans)` returns after enqueue, `unified_span_done()` queries that event, and `unified_span_finish()` fences, returns only finished prompt rows with correct `FinishSample` and row counts, and advances the chunk queue. Handle Host finishers without reading logits while the lane is still writing them. Retain eager prefill as the independent oracle and error fallback.
3. Extend the rank-0 protocol with explicit prefill flight ID, lane, ordered chunk rows/slot/position, final-row plan and mirrored KV events, plus slot-mapped decode begin membership. Before either rank enters a collective, rank 1 validates the complete message and KV event and sends Prepared. Preserve the pipe's deferred Ready for the prior tick; define a distinct span-finish ACK. Both ranks must execute the same globally ordered collective tickets on the one NCCL stream, with a compute-event wait for the producing lane and a NCCL-completion event waited by that lane. Do not infer a GPU fence from a TCP ACK or use the decode lane's event for prefill work. Any failure poisons both flights and drains or aborts both ranks; no release/reset/reuse until both lane events and the NCCL stream have completed.
4. Serialize large-vocabulary sampling across streams with a process-local sequence of CUDA events (sample call A's complete event must be waited by the next call's stream before its A/B/C kernels), or move `pd_sr_*` to caller-owned lane scratch and pass it through a versioned pack ABI. The event chain must cover all three launches, not merely the final ID readback; rank 1 does not sample. A host mutex protecting only launch calls is insufficient once kernels run asynchronously.
5. Wire `decode_pipe_begin_slots`, the span trait methods and slot lifecycle to the scheduler's existing overlap route. Keep `supports_overlap` false until all code and tests below pass. Unsupported Host/constraint/logprob cases use the existing drained serial path. Context/headroom and dummy-slot bounds from the accepted decode pipe remain in force.

## Required acceptance evidence

- Host tests: reject shared-slot lane membership, mismatched flight/ticket/position/KV event, unauthorized prefill while pipe active, invalid span capacity, double finish, and release/reset with either lane in flight. Unit-test finisher row count and sampler draw commits across a discarded lookahead and a cancelled request.
- Two-rank target-device probe: record per-rank CUDA events showing that prefill GPU work remains in flight when a decode tick is enqueued and that both lanes complete correctly. Host interleaving or concurrent HTTP requests alone is not overlap evidence. Assert matching executable, checkpoint and pack hashes on both Sparks and both process exit codes.
- Compare every final-row full logit (with the established TP=1 numerical tolerance), decode token ID and rank-0 RNG/draw plan against reset eager replay. Exercise bounded chunks crossing a 16-token KV page, a newly arrived prefill while another slot decodes, categorical sampling, cancellation mid-span, pipe drain, release and slot reuse. Verify rank-1 mirrored KV and recurrent state; prove no operations reference reused blocks until both lanes and NCCL have drained.
- Run the live scheduler with `supports_overlap` enabled only after the probe passes, assert actual simultaneous flight markers on both ranks and exact token/RNG parity under fixed and randomized arrival/cancellation/reuse. Fail closed if the pack lacks the required sampling protection. Then rerun the accepted decode-pipe suite as a regression, without weakening its acceptance checks.
